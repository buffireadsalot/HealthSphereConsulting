HEALTH SPHERE CONSULTING - SITE PLAN AND THEME PROTOTYPES

Open siteplan.html in a web browser. Use the palette buttons to switch between three designs; open homepage-preview.html to see the concept website.

FILES
siteplan.html - site purpose, audiences, scenarios, site map, typography, colors, wireframes, technical plan
homepage-preview.html - sample responsive homepage
styles/base.css - shared layout and fonts
styles/mineral.css - Mineral Teal theme
styles/oxblood.css - Oxblood & Stone theme
styles/slate.css - Slate & Copper theme
theme.js - local theme switching

All three themes use the same HTML, illustrating CSS separation taught in web programming classes. Google Fonts require internet access; system sans-serif fallbacks work offline.

This is a prototype, not a production business website. Do not publish contracts or confidential documents in a public GitHub repository.

Corrected package: keep siteplan.html, homepage-preview.html, and theme.js together; the styles folder must be alongside them.
